# 项目全面审查建议（2026-10-18）

七个专项并行审查的汇总：架构与代码质量、安全、UX/UI 与可访问性、功能完整性、测试与质量保障、文档与流程/运维、产品功能创新机会。各条目标注优先级（高/中/低）与证据位置。

实测基线：`npm test` 64/64 通过；`npm run build` 成功（dist 主包 402.51 kB / gzip 129.53 kB）；ops 部署引擎测试 30/30 通过；`npm audit --omit=dev` 0 漏洞；git 受控文件 120 个、无生成物、无凭据泄漏。

## 0. 总体评价

工程完成度显著高于一般课程项目水平：安全基线扎实（无注入/CSRF/越权漏洞）、部署与备份工程专业（不可变发布、事务回滚、加密备份）、测试真实可跑、可访问性基础良好（原生 dialog、combobox、键盘等效操作）、文档体量充分。

主要风险集中在四条线：
1. **可维护性**：极度压缩的单行源码 + sync.js 单例架构，使后续每项改动成本都很高；
2. **体验闭环**：费用表单丢输入、删除无撤销、断网假"已同步"、冲突恢复入口易消失——核心承诺（离线不丢、冲突可处理）的最后一公里没走完；
3. **运行风险**：已真实上线却零监控告警、备份无异地副本，是唯一存在真实数据丢失敞口的地方；
4. **文档矛盾**：设计文档与实现互相打架（导航项数、时区规则、权威版本），课程评审最容易被抓。

## 2. 安全

**总体：未发现可直接利用的 SQL 注入、CSRF 绕过、认证绕过或跨旅程越权。** SQL 全参数化；Origin+CSRF 双校验覆盖全部变更端点；membership() 覆盖全部 trip 端点；备份 AES-256-GCM+AAD；部署链防路径穿越/符号链接逃逸。

### 高
| # | 风险 | 证据 | 修复 |
|---|---|---|---|
| S-H1 | 单账号低成本全服 DoS：同步 SQLite 阻塞事件循环 + 无配额（reschedule moves≤10000 每 move 3-5 条同步查询；route.path max 100000；snapshot 无分页；trip 无每用户配额） | db.mjs:6；model.mjs:9,17,47-72；index.mjs:75-76 | moves 降数百/分片；snapshot 分页或对象数上限；trip/对象/用户配额；磁盘监控 |

### 中
- **口令哈希偏弱**：scrypt 默认 N=16384 无版本化/pepper → 显式 N=2^16~2^17 + 参数版本前缀（timingSafeEqual 已用 ✓）。
- **CSP 含 script 'unsafe-inline' + 'unsafe-eval'**：任何 DOM XSS 可升级为账号接管 → nonce/hash 化，评估 AMap 是否真需 eval。
- **OTP 弱**：验证码 hash 为裸 SHA-256（challengeId+code），明文 challengeId 存储返回 → HMAC(服务端密钥) 或 scrypt；验证过自动建号+30 天会话。
- **SMS pumping**：/api/auth/request 仅 10/IP/10min → 每号每日上限 + 图形验证码/PoW（课程环境短信渠道建议默认关）。
- **会话生命周期**：无滑动续期、无"登出全部设备"；sessions/challenges/receipts/leases 永不清理。
- **journey-backup.service 以 root 运行**（ProtectSystem 已缓解）→ 改 User=journey。
- **nginx**：无 80→443 跳转、无 limit_req、未 server_tokens off。

### 低
账号枚举（ACCOUNT_EXISTS + 时序差）；tripId 客户端生成可抢注/探测；4xx 回传 err.message 可能带路径；AMap 代理先全量缓冲再判 3MB、非 GET 穿透 SPA 返回 200；Origin 精确串比较是配置 footgun；authorized_keys 无 from= 限制。

## 7. 产品功能创新机会（当前需求未考虑的方向）

**成本红利**：operations + clock + SSE 模型对对象类型泛化，新增协作对象（任务/清单/表态）免开发同步/冲突/离线/软删除。

### Top 5 值得做
1. **费用均摊与结余**（谁欠谁）：expense 加"参与人/付款人"两字段 + 纯前端结算算法 + 团队页结余，同步零改动；只算不付。熟人结伴第一大钱上痛点。
2. **今日出发卡**：出行日顶部聚合"下一项活动 + 建议出发时刻（算法已验收）+ 一键导航 + 天气"；离线天然可用，成本几乎最低。
3. **任务分工**（谁订酒店/谁买票）：新 object kind `task` + 认领状态，复用同步机制；防止"以为对方订了"。
4. **按天天气卡**：高德天气 API 现成，每天都会看。
5. **AI 行程草案 + 自然语言添加**：生成进"候选"体系（用户逐项排入/删改），破空行程冷启动；E18（自然语言）可先做。

### 差异化杀手锏
- **"出门看一眼"卡**（出发时刻+天气+同伴签到+一键导航，离线可用）：无竞品在同一份共享行程里做全。
