## 一、范围与结论

1. **生成资产一致、`--check` 只读**：`node scripts/generate-design-tokens.mjs --check`、`node scripts/generate-destination-timezones.mjs --check` 均通过；`node scripts/check-design-contrast.mjs` 90 项通过。两个 `--check` 分支只做 `readFileSync` 比较后 throw（`generate-design-tokens.mjs:56`、`generate-destination-timezones.mjs:13-15`），不会写文件。`shared/destination-timezones.json` 与 `generate-destination-timezones.mjs` 本次无改动，仍与生成物一致。
2. **Token 源同步良好，但导出面不完整**：`design/tokens.json` 新增 map/widget/note/ink/highlight/peer 共 34 个键，CSS 生成的是整个 palette，而 Swift/Kotlin 只按 `colors` 白名单导出（`scripts/generate-design-tokens.mjs:36-46`），白名单漏掉 `mapAccent/mapAccentSoft/mapRoute/mapRouteMarker` 四个键 → 原生拿不到 `--map-route` 同源值，是下面「地图取色不一致」的直接成因。
3. **与 Web 功能对齐整体到位**：链接规范化（三端同一套规则，含裸域名补 https、拒绝非 http(s)、拒绝含空格主机）、费用日期跟随活动/关联被删除后「未记录日期」、收藏聚合阈值与迟滞（同标记 34/40、混合 24/30 像素）、计划日稳定 ID、时区推荐列表（目的地→本机→全部）、日期调整两步流程，均与 Web 行为一致，且有新单测覆盖主体规则。
4. **跨端不一致仍在 6 处**（收藏标记默认值、地图编号顺序/取色、同地点双标记、预设排序/入口、日期未定旅程改期、删除计划日改期），其中收藏标记默认值是契约级偏离，列为 P1。**未发现 P0**（数据丢失/鉴权绕过/远程执行）。
5. **白板兼容结论**：`board`/`boardItem` 不造成协议问题。主快照只含 `board`、不含 `boardItem`（`app/CONTRACT.md:20-22`），原生端只按已知 `kind` 取数（行程/地图/费用/day/favorite/activity/route/markPreset），未知对象随快照 JSON 原样持久化（`JourneyStore.kt:303`、`JourneyStore.swift:269` 存整份快照），本地投影只按操作合并 payload（`Domain.kt:225-260` 无 kind 白名单），不重写、不回传整份对象 → **不会丢白板数据，读取安全忽略**。唯一副作用见 B7（已删除内容列表范围）。

## 三、与 Web 一致性（逐项）

- **一致**：链接规范化（裸域名/https 补全、`javascript:`/`ftp:` 拒绝、host 校验、协议小写化，两端单测与 `app/src/activity-url.js` 逐条对齐）；费用 `date=null` 跟随活动计划日、关联活动删除后空日期「未记录日期」、显式日期优先；费用标题回退「已支付/预计」；收藏聚合阈值/迟滞与排序兜底（priority→id，Web 记录称收藏无不可变创建时间，故与 Web 实际结果等价）；`planDayId` 稳定 ID；预设改名不重命名收藏、删除预设保留标记（服务端级联 + 原生乐观投影两端均实现）；时区选择器「目的地→本机→全部」与 Web `app/src/Settings.jsx:329-345` 同步。
- **不一致**：收藏默认标记（A1）、地图编号顺序（A5）、同地点双标记（A6）、标记/路线取色（A7）、预设新建顺序与入口（A8）、日期未定改期（A3）、删除计划日改期（A4）、已删内容列表范围（B7）。
- **白板/小组件**：见第一节第 5 点，原生安全忽略、无协议兼容问题；唯一建议是 B7 的已删除内容展示收敛。
