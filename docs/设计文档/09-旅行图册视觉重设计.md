# 同行 · 旅行图册视觉重设计

状态：本页保留 `10d4dd2` 的历史设计与验收记录。2026-11-02 已按新审查改为森林绿 / 海图蓝双主题，字体、材质和设置结构的当前实现见[双主题与设置修复](../实施记录/2026-11-02-双主题与设置修复.md)。

## 设计依据

采用用户指定的 Anthropic frontend-design skill。官方来源：https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md 。先明确使用者与任务，再确定视觉方向、实施和截图审查。

产品面向结伴出行的朋友与家人，兼顾组织者、普通成员和途中临时查看计划的人。核心工作是把零散想法转成同一份可协作的旅行安排。真实内容以旅程名、日期、地点、时间、费用和成员权限为主；既要支持空白计划，也要容纳长名称、多币种、未定时间和离线状态。页面保留原有文案、路径、数据及事件逻辑。

## 逐页目标

| 页面或流程 | 目标用户 | 核心任务 | 内容特点与设计回应 |
| --- | --- | --- | --- |
| 登录、注册、会话恢复 | 首次访问者、返回成员 | 进入账号，继续已有计划或接受邀请 | 简短表单和明确错误；路线图说明结伴旅行主题，输入区保持安静 |
| 我的旅程 | 参与多个旅程的成员 | 继续最近旅程，创建或加入旅程 | 旅程名、日期、状态、同行者是真实索引；最近旅程作为主封面，其余为小图册 |
| 创建、加入 | 发起人、受邀者 | 定目的地与日期，选择协作方式或确认邀请 | 信息逐步填写；日期并排，额外配置沿用折叠，保留两类团队解释 |
| 行程 | 计划者、途中查看者 | 按天浏览、编辑、排序、查看路程与下一站 | 日期索引和路线节点组织时间顺序，时间与标题分级，手机保留切日和添加按钮 |
| 活动、路线编辑 | 共同规划者 | 安排名称、时间、地点、缓冲和交通 | 自动保存和真实验证反馈保留；字段间距、分组、焦点和完成操作统一 |
| 地图、地点详情与收藏 | 查地点、路线的成员 | 搜索、收藏、选址、导航与查看某天路线 | 地图保持全屏；搜索、图例、路线与详情面板使用不喧宾夺主的纸白表面 |
| 费用、费用编辑 | 记账成员、核对预算的人 | 区分已支付与预计，按日期、活动查账 | 实际金额是视觉重点，等宽数字特性用于金额；日期分组采用账本行，保留多币种 |
| 旅程管理、日期调整 | 创建者、管理员、成员 | 改名称、目的地、时区、日期及团队模式 | 表单与导航入口分层；删除恢复与退出维持危险操作色和原有权限 |
| 成员与邀请 | 管理员、受邀成员 | 查角色与权限，邀请同行者 | 成员行、头像和菜单统一；邀请编码与二维码保留真实内容 |
| 已删除内容、旅程恢复 | 有恢复意愿的成员 | 判断删除状态、表态或恢复 | 保留原解释和集体规则；统一标签、操作与反馈层级 |
| 个人设置、同步设置 | 所有成员 | 管理账号、外观、无障碍和同步恢复 | 统一表单与状态颜色；保留减少动态、透明度与系统主题选项 |

## 视觉方案

主题是“旅行图册”：路线、地图等高线、地点首字和日期索引都来自产品本身。没有添加假城市、假评价或装饰性的统计数字。

基础色：航线蓝 `#176B88`、海图墨蓝 `#193D51`、纸白 `#FFFFFF`、薄雾蓝 `#EDF3F6`、边界蓝灰 `#CEDDE5`、次级文字蓝灰 `#5B7280`。深色模式采用深海蓝背景和明亮蓝色强调，继承既有危险操作色。

字体：主要中文页面标题使用本地托管的 Noto Serif SC 固定标题子集，并以宋体回退承接动态中文标题；正文和控件以 PingFang SC / Microsoft YaHei 承接中文，Manrope 处理拉丁字符与数字。字体本地托管，不依赖运行时外部字体请求；附 OFL 授权。字体只保留所需固定标题字形，避免为少量展示标题加载完整中文字库。

布局：正文左对齐；登录采用地图/表单双栏，手机改为上下结构；旅程首页采用大封面和小图册；工作区保留现有导航收缩和地图全屏行为；行程强调顺序，费用强调对齐，设置强调可扫读的分区。

```text
登录（电脑）          工作区（电脑）
品牌 / 个人设置       导航 | 旅程 / 同步 / 成员
路线图 | 登录表单     导航 | 页面标题
旅行宣言              导航 | 日期 / 筛选 / 主操作
                      导航 | 对应任务内容

手机工作区
旅程 / 同步 / 成员
页面标题
日期 / 筛选
任务内容
底部主导航
```

方案复核：拒绝使用与旅行无关的渐变背景、重复玻璃卡片和循环悬浮装饰。把辨识度集中在路线地图和图册封面；时间、日期、账目和表单各自采用适合内容的结构。序号只用于现有真实活动顺序；不新增无意义的编号和英文眉题。

动效：保留用户操作触发的导航选中滑移、地图侧栏收缩、切日和折叠过渡。登录地图只响应指针轻微移动，取消原有持续虚线漂移和浮动动画。沿用减少动态偏好与键盘焦点机制。

## 实现边界

视觉变量集中在 app/src/atlas.css，避免改动原生客户端共享生成 tokens。所有 JSX 改动限于登录插图和把既有无障碍页面标题展示出来；业务协议、账号、同步、路由与数据模型保持原实现。正式站点和用户数据库不用于视觉验收；测试采用独立测试服务与测试数据。

## 2026-11-02 修订

这份文档保留蓝色图册试验的历史背景。当前设计以[审查索引](../评审输入/前端设计审查索引.md)及其两份报告为准：森林绿为默认，海图蓝可选；颜色和材质独立，纯平样式由“减少透明效果”控制。Web、iOS、Android 共用 `design/tokens.json`。

Manrope 常规体与 24 字衬线子集已移除，动态文字统一使用系统字体。海图蓝只在固定品牌和标语使用系统衬线字体，旅程名、地点名与弹窗标题保持无衬线。

可复跑的检查，从 `app/` 执行：

```sh
npm run check
npm run test:e2e -- personal-settings.spec.mjs atlas-review.spec.mjs design-review-1101.spec.mjs map-layers.spec.mjs
```

六种配色组合由 `JOURNEY_REVIEW_PALETTE=forest|atlas`、`JOURNEY_REVIEW_THEME=light|dark|system` 参数选择。截图测试等待实际页面内容出现后再拍摄，样例账号和数据只存在于测试服务器。完整修改与本轮证据见[实施记录](../实施记录/2026-11-02-双主题与设置修复.md)。
