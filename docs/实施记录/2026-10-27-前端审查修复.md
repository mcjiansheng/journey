# 2026-10-27 前端审查修复

根据《「同行 Journey」前端设计与交互审查（2026-10-26）》处理高、中、低优先级问题，保留现有墨绿、暖白和玻璃样式。修改在 `dev` 开发。

## 修复内容

| 审查项 | 现在的行为 |
| --- | --- |
| H1 地图与行程断开 | 地图默认显示活动编号和收藏星标，支持全部、行程、收藏筛选；从行程进入时跟随当前日，首次按标记调整视野。返回地图保留视野；修改旅程目的地仍会定位到新城市。 |
| H2 恢复到设置页 | 继续旅程时将管理页恢复为行程页，选中日期和草稿照常保留。 |
| H3 路程占位 | 未设置的路程改为卡片间的小入口。两端有坐标时自动估算，结果直接显示；查询失败后联网会重试。没有生成待补路程对象。首项出发地只在有具体时间时提示。 |
| H4 编辑器保存与关闭 | 活动和费用统一使用标题栏“完成”，显示保存状态。“稍后继续”保留未完成草稿并关闭；点击遮罩不关闭。已有活动可直接在编辑器里删除。编辑器固定顶部位置，校验信息变化不会移动正在点击的控件。 |
| H5 操作一致性 | 行程和费用删除收在菜单里，并提供撤销；取消收藏也可撤销。首页有继续旅程时，创建和加入均为次级按钮。 |
| M1 日期切换 | 手机有吸顶日期条，支持下拉、左右按钮和滑动切日。 |
| M2 时段排序 | 新建和更改时间时按时段或具体时间确定默认位置，普通编辑保留手动排序。处理精确时间槽位、重复顺序值和连续键盘移动。 |
| M3 卡片密度 | 删除重复编辑按钮和“灵活安排”占位。点标题编辑，地点行打开地图，旁边可外部导航；手机拖动柄在排序模式显示。 |
| M4 同步入口 | 同步按钮直接打开“保存与同步”；手机遇到离线、待处理等状态显示文字。 |
| M5 设置归属 | 旅程页“设置”改为“管理”，只保留旅程操作；个人设置从头像进入，手机头部也有本人头像。移除团队类型下面的空白分隔。 |
| M6 时区查询 | 创建无需等待地理编码；尚无查询结果时使用设备时区。旅程管理可修改时区，服务端允许该字段修改并保留原日期和时间。 |
| M7 记账 | 金额显示币种和占位提示；费用可录入日期并按日期筛选；预计费用可一键按预计金额登记已付；多币种合计分行标明代码。旧费用显示“日期未记录”，可补写。 |
| M8 协作表态 | 活动卡显示不参加人数和希望删除的人数进度。 |
| M9 初始焦点 | 创建表单聚焦输入，成员、个人设置等普通弹窗聚焦标题。 |
| M10 手机地图控件 | 搜索与日期筛选合成同一浮层，日期使用紧凑显示。 |
| 其余打磨 | 编辑器所在日使用月/日、已有活动以名称为标题；移除重复页面大标题；行程和账本统一列宽；地图保持完整桌面侧栏；空地图增加可关闭引导；行程增加今天、下一项及外部导航。 |

## 并发与草稿

活动和费用保存都绑定打开编辑器时的账户与旅程，关闭后晚完成的写入不会进入新旅程。草稿仍按字段清理，晚到的旧保存不会覆盖新输入。删除与撤销也绑定原旅程；连续排序按上一次移动后的快照继续计算。
