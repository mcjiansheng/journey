# 白板与小组件功能

依据：Antigravity 对话任务（`.agents/teamwork/ORIGINAL_REQUEST.md`）、[10-白板](../设计文档/10-白板.md)、[CONTRACT.md](../../app/CONTRACT.md) 与 `prototype-board/`。开发分支 `dev`。

## 修改

### 服务端

- 新增 `board` / `boardItem` 对象模型：`frame`、`z`、`content`（note / text / emoji / image / link / widget / stroke / shape）、`style`、`linkedActivityId`、`createdBy` 的严格校验；`validateBoardItem` 按内容类型校验样式（便签颜色、文字字号、画笔颜色与粗细、图片相框、小组件规格），未知类型拒绝颜色 / 规格 / 相框。
- 新建旅程时自动写入 `default-board`；`GET items`、presence 与 `references()` 对 `default-board` 兜底，避免 404 / `INVALID_REFERENCE`。
- 白板增量接口 `GET /api/trips/:id/boards/:boardId/items?since=`；`objects.changedCursor` 迁移（migration 4）与 `(tripId, kind, changedCursor)` 索引；主快照排除 `boardItem`；`boardItem` 操作只返回 receipt，不重复全量快照。
- 容量：每旅程 active board ≤ 20、每 board active boardItem ≤ 2000，超限返回 409。
- 素材上传 / 下载：magic bytes 校验 JPEG / PNG / WebP / GIF，静态图 ≤ 1.5MB、GIF ≤ 5MB、缩略图 ≤ 300KB；同 id 同内容幂等、不同内容 409；下载不可变缓存并设置 `nosniff`；旅程永久清除时删除素材目录。
- presence：仅内存维护，HTTP 上行、SSE `event: presence` 下行，15 秒无心跳广播 leave，15 次/秒/设备限频。

### 客户端

- `board-sync.js`：`normalizeBoardItem` 从 payload 提升 `frame / z / content / style / linkedActivityId / createdBy`；`cleanBoardItemPatch` 白名单字段并把 `locked` 折叠进 `style`；IndexedDB 缓存、`since` 增量拉取、SSE 合并与离线队列。
- `Board.jsx`：全视口画布、选择 / 拖动 / 四角缩放、统一 z 序、锁定、撤销 / 重做、最近删除、贴纸面板、图片与 GIF 上传、画笔 / 荧光笔 / 橡皮 / 形状、文字与链接卡；只渲染与视口相交（外扩 200px）的对象。
- `BoardItem.jsx`：七类元素渲染；便签 `onInput` 记录、`blur` 提交，失焦前先提交再清除选择。
- 小组件：7 种（activity / day / place / route / countdown / clock / expense）与规格、已移除状态、加入行程、行程 / 地图 / 费用「贴到白板」、白板导航入口。
- 修复视口初始化：只在加载完成且已有内容时居中，创建首个对象不再跳屏；新贴纸在中心被占用时按原型向右下错开。

### 设计 token

- `design/tokens.json` 增加 widget 品牌色、便签 6 色、画笔 / 荧光笔 / 同伴色，浅色与深色各一套；由脚本生成到 Web 与 Android / iOS。

## 代码审查

### 规范性

- Zod `.strict()` 贯穿 board / boardItem schema 与 patch；`validateBoardItem` 按 `content.type` 校验 `style`，缺目标、多余目标、规格不符均有明确错误。
- 主快照不含 `boardItem`，增量接口按 `changedCursor` 排序返回；操作回执只含 receipt，避免全量快照膨胀。
- 客户端提交前经 `cleanBoardItemPatch` 白名单清洗，不携带 `id / tripId / state / generation` 等顶层字段。

### 安全性

- 所有 board 接口先 `withMember` 校验旅程成员身份；items 查询按 `tripId` 过滤，跨旅程 `boardId / activityId` 引用返回 `INVALID_REFERENCE`。
- 素材上传校验 magic bytes 与体积，拒绝伪造 Content-Type；下载设置 `X-Content-Type-Options: nosniff` 与不可变缓存；清除旅程时删除素材目录。
- presence 仅内存、按用户 + 设备限频，选中 / 编辑 / live 的 item 必须属于当前白板。

### 性能

- `changedCursor` 索引支撑增量拉取；客户端 IndexedDB 缓存 + `since` 增量 + SSE 合并，避免全量重复。
- 主快照排除 `boardItem`，减少每次同步负载；`boardItem` 操作省略 snapshot。
- 画布按视口（外扩 200px）裁剪渲染，配合 2000 项硬上限，避免大量不可见对象占用渲染与定时器资源。

### 一致性

- 双调色板设计 Token 由 `design/tokens.json` 单点生成到 Web 与移动端，对比度检查 90 项通过。
- 行程 / 费用数据与小组件双向响应：改名、删除、恢复后小组件同步更新或进入「已移除」状态。
- LWW 字段级时钟与 generation 并发检测沿用既有同步协议；boardItem 删除与恢复不走表态，任何成员可直接执行。
