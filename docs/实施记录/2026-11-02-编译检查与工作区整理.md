## 工作区整理

原先 `project.pbxproj` 有大量 Xcode 格式改动。解析后与 Git 版本比较，实际设置变化只有 Debug、Release 两处个人开发团队。

- 将个人团队迁入 `mobile/ios/Config/Signing.local.xcconfig`，加入忽略，保留本机值。
- 新增共享 `Config/Signing.xcconfig`，通过可选 include 读取个人配置。生成器将它设为项目级构建配置，应用和测试 target 均继承。
- 重建 `project.pbxproj`，保留全部源文件和 target。再次运行生成器，工程与 scheme 内容不变。
- 增加 iOS 结果包、归档、IPA 和 JVM 崩溃日志的忽略规则。构建缓存、APK、截图与日志继续保存在已有忽略目录。
- 原项目文件保存在 `.local/evidence/build-review-1102/ios/project.before-cleanup.pbxproj`。本轮未删除历史验收文件。
