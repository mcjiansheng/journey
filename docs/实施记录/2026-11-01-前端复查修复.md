## 修改结果

| 编号 | 修改 |
| --- | --- |
| R3-1 | 侧栏以导航图标为锚点，用 `clip-path` 收缩外形，统一 280ms 动画。文字先淡出、后淡入；选中底板宽度随按钮同步变化。首次地图组件和 SDK 初始化等侧栏动画结束后执行，中途返回会取消待初始化任务。保留个人设置里的自动收起开关。 |
| R3-2 | 当天日期显示“今天”和圆点。桌面“回到今天”“下一项”放在日期条左侧；手机提供定位图标及下拉菜单入口。切换日期不会增加、移除整行工具栏。 |
| R3-3 | 三端共用翡翠绿、青蓝、深青环境光 token；删除深色暖黄及写死的橄榄色。生成器支持透明度，正确输出 CSS / Swift RGBA 和 Kotlin ARGB。跟随系统与手动深色使用相同背景、侧栏和阴影。 |
| R3-4 | 头像重叠缩到 4px，保留 2px 表面色描边，前面的头像盖住后面的底色。手机顶栏显示首个头像与剩余人数。 |
| R3-5 | 普通旅程卡片的目的地字水平、垂直居中。 |
| R3-6 | 手机继续旅程色块缩到 56px，标题使用 `text-wrap: pretty`。样例“南京周末 · 秋日漫游”没有单字落行。 |
| R3-7 | 活动费用按币种区分“已付”“预计”并显示笔数。点击后进入费用页，仅显示该活动的关联费用，可清除筛选。 |
| R3-8 | 日期条按内容宽度排布，溢出后显示边缘渐隐和桌面滚动箭头。选中日期滚入视区；普通重新渲染不会拉回手动滚动的位置。焦点环只在键盘操作时出现。 |
| R3-9 | 费用日期筛选共用横向标签组件，显示溢出提示并跟随选择滚动。 |
| R3-10 | 成员更多按钮移至姓名行右侧，邀请权限开关另起一行。 |
| R3-11 | 手机已同步状态显示云朵对勾，保留“已同步，查看保存与同步”的无障碍名称。 |
| R3-12 | iOS、Android 均在模拟器运行截图用例，各拍齐亮暗色 12 张，结果见下方原生记录。 |

本机未配置网页高德 Key，真实 SDK 画布保留用例无法完成。地图初始化、取消和销毁用可控 SDK 替身验证；截图中的网页地图为无 Key 状态。
