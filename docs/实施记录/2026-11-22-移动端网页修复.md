# 2026-11-22 移动端网页修复

依据：[移动端网页问题追踪清单](../评审输入/移动端网页问题追踪清单.md)与 [2026-11-22 移动端地图草案审查](../评审输入/2026-11-22-移动端地图草案审查.md)。分支：`dev`。`draft/mobile-map-ui` 只作参考，未合并。

## 修改

### 地图（MOB-006/007/008/018/019/021）

- 以草案结构为底稿精简实现：顶部搜索区与胶囊条（路线日期、筛选、手机图例开关），底部抽屉两段式（半屏 / 全屏，把手可拖，下拖关闭）；浏览态底部为概览条。
- 用 `ResizeObserver` 计算 `--map-top-clearance` / `--map-bottom-clearance`，`setFitView` 与选中地点居中避开上下浮层。
- **决定（用户 2026-11-22 确认）**：手机地图的详情、列表、搜索、筛选、手动填写、选点状态隐藏底部导航，左上角箭头为「返回地图总览」，回到浏览态后才显示底栏与「返回我的旅程」。因此手机端离开地图前会先退出地点详情，详情不再跨页面保留（桌面不变）。
- 恢复手机 `+` / `−` / 定位按钮，随抽屉避让，抽屉过高或搜索时隐藏；手机图例收进顶部开关弹层（点外部、Esc 关闭）。
- 收藏标记手机端折叠为摘要行；地点操作按钮不折行、主按钮占比 1.25（桌面同样受益，字号不变）。
- 与草案不同：不引入 `temp-amap.js`（无 Key 仍显示「地图暂时无法加载」）；去掉列表区触摸接管手势；关闭地点时复位「更多操作」；`exitSubViewRef` 改在 effect 中赋值；断点集中为常量。

### 行程（MOB-001/002/004/005）

- 日期条：可见文字后紧跟箭头，原生 `select` 透明覆盖在上，保留无障碍名称；左右按钮 44px。
- 当天操作：手机改为底部操作面板（`Modal`，一行一项、统一图标、删除单独分隔，点遮罩或返回关闭）；桌面保留原位面板，补点外部 / Esc 关闭；`···` 有展开态样式。
- 路程槽与添加路程手机 44px；地点、导航图标与「回到今天」扩展触控区；宽屏触屏常显添加路程与拖动手柄。
- 行程工具栏底线与内边距只在桌面生效；`itinerary.css` 三段手机断点合并为一段。

### 菜单、触屏与弹窗（MOB-003/013/014/015/017）

- `details-menus.js`：活动、费用、成员的「更多」菜单只开一个；点外部、Esc、按钮滚出屏幕即收起；下方被底栏、添加按钮或屏幕边缘挡住时向上展开。
- 全站 `:hover` 规则包进 `@media (hover: hover) and (pointer: fine)`（脚本处理，混合选择器拆分，规则顺序不变）；触屏选中的图集显示翻页箭头。
- 活动编辑器「完成」对触屏同样不先失焦。
- 三处 `confirm()` 改为应用内确认框（`useConfirm`）；不支持 `BarcodeDetector` 的浏览器不显示扫码按钮，提示用系统相机。
- 旅程设置内联输入框加浅底与焦点框，手机上下排列。
- 未改：编辑弹窗手机顶部定位（为软键盘留空间，属有意设计）。

### 白板（MOB-009/010/011/012）

- 格式栏手机按钮 40px，放不下时折行；颜色弹层下方空间不足时向上展开（全端）。键盘上方固定工具条未做。
- 手机工具 44px，可横向滚动时有工具的一侧淡出；恢复缩放百分比与「适应全板」。
- 白板切换器按顶栏右侧胶囊实际宽度让位；贴纸抽屉抓手 96×36；选中浮条按钮 44px。

### CSS 收口（MOB-016，第一步）

- 删除 `styles.css` 手机断点中 53 条从未生效的声明（后面有相同选择器、相同属性的基础规则）。渲染结果不变。
- 九段断点未合并：合并会让上述类型的规则顺序改变，需要截图对比，留待后续。

## 地图署名避让修正（2026-11-22）
