# 2026-11-28 原生 N1（Android）：小功能对齐

依据：[11-原生端功能对齐](../设计文档/11-原生端功能对齐.md) 第 1–4、6 节与 N1 工作包。分支：`native/N1-android`。

## 修改内容

### 1. 共享用例与邀请链接规则对齐
- `mobile/tools/generate-fixtures.mjs` & `mobile/fixtures/place-information.json`：导入 `app/src/place-information.js`，新增 `placeInformationFixture()` 生成 31 条 `safePlaceUrl` 与 `normalizePlaceInformation` 共享用例（覆盖协议校验、凭据过滤、高德图片 HTTPS 升级、多个电话分隔符、营业时间优先级、`scenic/dining/cinema/hotel` 深度信息、`detailUrl` 编码及空数组类型保护）。
- `mobile/android/app/src/main/java/wang/jscloud/journey/Domain.kt`：将 `normalizeInvite` 对齐网页 `Entry.jsx` 的 `inviteCode`（优先取 `invite` 查询参数并解码，空值或无参数时回退到 `path` 最后非空段，尾斜杠与非法 URL 安全处理）。

### 2. 新增模块（新逻辑独立成文件）
- `PlaceInformation.kt`：按 `app/src/place-information.js` 移植 `safePlaceUrl`、`normalizePlaceInformation`（含 `biz_ext` 平铺兼容与 `type` 取末段、高德照片强制 HTTPS）、`fetchPlaceDetail` / `searchPlacesWithInfo`（调用 `/_AMapService/v3/place/detail` 与 `/text`，不向持久化 `Place` 写入 `information` 字段），以及 `PlaceInformationSection`（摘要展示照片、类别、营业时间；展开展示简介、可点击拨号电话、地点网站与高德查看链接；复用现有 OkHttp 客户端加内存 LRU 缓存加载图片，失败静默隐藏）。
- `ItineraryJump.kt`：按 `Itinerary.jsx` 移植 `tripClockAt`（严格按旅程目的地 `trip.timezone` 计算当地今天日期与 24 小时制时刻，不使用设备时区）、`findTodayDay`、`findNextActivity`（当天第一条精确时间且 `endDayOffset > 0` 或 `(end || start) >= clock` 的活动）、`canDeleteDirectly`、`deletedObjectTitle` 与 `ItineraryJumpBar`（「回到今天」「下一项 HH:mm」）。
- `InviteQr.kt`：基于 `com.google.zxing:core` 与 CameraX 实现 `encodeQrMatrix`、`decodeQrFromLuminance`、`renderQrBitmap`、`decodeQrFromBitmap`、`InviteQrCard`（纯白底板 + 深绿码点确保深色模式下也可扫码，支持复制编码/复制链接/分享）与 `QrScannerDialog`（运行时申请 `CAMERA` 权限，支持无相机设备提示、CameraX 实时预览扫码及从相册选择二维码图片兜底）。
- `MapPlaceSheet.kt`：基于 Material 3 `ModalBottomSheet` 实现地图地点详情底部面板（支持半屏 `PartiallyExpanded` 与全屏 `Expanded` 切换），操作按钮区使用 `FlowRow` + `softWrap = false` 确保 390px 窄屏完整显示不截断，串联 `PlaceInformationSection`、标记预设、自定义标记与路线估算。

### 3. 共用文件接线与权限
- `mobile/android/app/src/main/java/wang/jscloud/journey/MainActivity.kt`：`onCreate` 使用 `normalizeInvite`；`JoinSheet` 接入「扫描二维码」入口；`ItineraryScreen` 接入「今天」标签、`ItineraryJumpBar`、卡片「下一项」徽章、当天菜单「删除这一天 / 希望删除这一天」与「调整日期与天数」、已删除计划日标题与关联活动计数；`ObjectActions` 对 `day` 显示「删除这一天」。
- `mobile/android/app/src/main/java/wang/jscloud/journey/Management.kt`：`InvitesSheet` 接入快捷有效期芯片与 `InviteQrCard`；已删除内容区使用 `deletedObjectTitle`。
- `mobile/android/app/src/main/java/wang/jscloud/journey/NativeMap.kt`：接入 `searchPlacesWithInfo`、`fetchPlaceDetail` 异步拉取与 `MapPlaceDetailSheet` 底部面板。
- `mobile/android/app/src/main/AndroidManifest.xml`：新增 `CAMERA` 权限与可选相机特性声明（`required="false"`）。

### 4. 新增 Gradle 依赖及理由（`mobile/android/app/build.gradle.kts`）
离线 Maven 仓库 `.local/android-cached-maven` 不含二维码与相机库，按 `11-原生端功能对齐.md` §3.1 改用在线构建并新增以下最小依赖：
- `com.google.zxing:core:3.5.3`：纯 Java 二维码编码与解码，无 Google Play Services 依赖，兼顾 AOSP 设备与 JVM 单元测试。
- `androidx.camera:camera-core:1.4.1`、`camera-camera2:1.4.1`、`camera-lifecycle:1.4.1`、`camera-view:1.4.1`：Android 官方 CameraX 扫码预览与图像分析框架，同样不依赖 Play Services。
- 地点照片直接复用现有 OkHttp + `BitmapFactory` 加载，未引入额外图片库。

### 5. 单元测试与端到端用例
- `mobile/android/app/src/test/java/wang/jscloud/journey/SharedFixturesTest.kt`：接入 `place-information.json`，逐条比对 `safePlaceUrl` 与 `normalizePlaceInformation`（31 条全覆盖）。
- `mobile/android/app/src/test/java/wang/jscloud/journey/N1FeaturesTest.kt`：覆盖跨时区 `tripClockAt`、「回到今天 / 下一项」边界、`normalizeInvite`、ZXing 二维码生成/解码往返、删日权限与已删除标题、`MockWebServer` 验证 `fetchPlaceDetail` 解析 `biz_ext` 与高德图片 HTTPS 升级。
- `mobile/android/app/src/androidTest/java/wang/jscloud/journey/NativeFlowTest.kt`：新增 `n1LightAndDarkScreenshots`，在浅色/深色模式下完整覆盖加入页扫码按钮与邀请链接解析、今日行程跳转、删日、地图半屏/全屏地点详情与邀请二维码生成。
