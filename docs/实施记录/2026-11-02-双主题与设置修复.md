## 验证入口

从 `app/` 执行：

```sh
npm run check
npm run format:check
npm run test:e2e -- personal-settings.spec.mjs atlas-review.spec.mjs design-review-1101.spec.mjs frontend-review-shell.spec.mjs map-sidebar-preference.spec.mjs map-layers.spec.mjs navigation.spec.mjs login.spec.mjs
```

在 macOS Codex 中，浏览器命令按 `AGENTS.md` 以授权方式启动。配色矩阵例子：

```sh
JOURNEY_REVIEW_PALETTE=atlas JOURNEY_REVIEW_THEME=dark npm run test:e2e -- atlas-review.spec.mjs design-review-1101.spec.mjs
```

`forest / atlas` 与 `light / dark / system` 共六种组合。测试覆盖 1440、768、390、320px，先等待页面内容出现再截图；额外检查选中填充、数字字重、系统透明偏好、地图面板颜色、账号跨会话恢复和失败回滚。

## 实现位置

- `design/tokens.json` 与 `scripts/generate-design-tokens.mjs`：颜色和材质的共同来源。原生 CI 在检查生成文件前安装锁定的 Node 工具依赖。
- `app/src/components/PersonalSettings.jsx`、`personal-settings.css`：分类设置及预览控件。
- `app/src/appearance.js`、`app/public/appearance-init.js`：账号偏好、保存状态和首次加载外观。
- `app/src/palette-atlas.css`：图册主题专用装饰，其余结构样式留在对应组件。
- `mobile/ios/Journey/Theme.swift`、`JourneyApp.swift`、`JourneyStore.swift`：原生颜色、分类设置和偏好保存。
- `mobile/android/app/src/main/java/wang/jscloud/journey/Theme.kt`、`Settings.kt`：Compose 主题与分类设置。

原始审查 Markdown、HTML、样稿和图片均保留；报告中的旧行号描述修改前代码。当前执行状态以审查索引为准。
