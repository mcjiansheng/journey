# 2026-11-28 原生 N3 Android：地图筛选与图例

依据：[11-原生端功能对齐](../设计文档/11-原生端功能对齐.md) 第 3–4、6 节及第 5 节 N3 工作包。开发分支：`native/N3-android`（独立工作目录 `../journey-N3-android`，基线网页 `main` `3d5a2e4`）。

## 修改

- **`mobile/android/app/src/main/java/wang/jscloud/journey/MapMarks.kt`**：
  - 按 `app/src/marks.js`（`3d5a2e4`）补齐 `markIconNames`、`defaultMark()`（`star:amber`）、`rawMark()`、`effectiveMark()`、`markLabel()`、`markGlyph()`、`markColorHex()`。
  - 对齐 `markKey(mark)` 口径：未设置标记或空对象返回 `"default"`，避免 `mark == null` 的未分类收藏误匹配 `star:amber` 预设；修正 `MarkEditor` 的 `used` 计数与 `MarkPresetManager` 空名预设回退 `markLabel`。
- **`mobile/android/app/src/main/java/wang/jscloud/journey/MapFilter.kt`**（新增）：
  - 纯函数移植 `app/src/MapView.jsx` 与 `app/src/domain.js` 规则：`placeLocated`、`placeKey`、`placeCategory`（`餐饮` / `住宿` / `景点` / `交通` / `其他` 正则优先级）、`visibleDays`、`dayLabel`、`activePresets`、`resolveMarkFilter`、`presetDisplayName`、`usedPresets`、`buildMapLegend`、`isPlaceArranged`、`filterMapData`。
  - 关键规则一致：图例仅展示已被至少一条活动收藏显式使用的预设并按全部活动收藏计数（不受当前筛选条件缩减）；无效或被删预设自动清空 `mark` 筛选；图层切为「收藏」时不渲染任何路线并将原先与活动重合的收藏恢复显示；保存路线的匹配同时校验 `fromId`、`toId`、`state == "active"`、非空 `path` 与 `routeSignature`。
  - 按 Material 3 原生惯例新增 `MapFilterBar`（路线日期选择、`筛选` 计数 Chip、`图例` Chip）、`MapLegendStrip`、`MapFilterBottomSheet`（显示 / 标记 / 类别 / 安排状态 `FlowRow` 筛选与重置）及 `MapLegendBottomSheet`。筛选与图例选择仅保留在本机视图状态，不写共享数据。
- **`mobile/android/app/src/main/java/wang/jscloud/journey/NativeMap.kt`**：
  - 将 `filterMapData`、筛选/图例条及底部面板接入地图页，新收藏按 `CONTRACT.md` 写入 `mark: null`，收藏列表展示分类与「· 已安排」状态及空筛选提示；保存的路线与临时起终点路线在图层为「收藏」时不绘制。
- **`mobile/android/app/src/test/java/wang/jscloud/journey/MapFilterTest.kt`**（新增）：
  - 用 `mobile/fixtures/itinerary.json` 校验 `visibleDays` 与 `dayLabel` 全部共享用例，并覆盖未分类收藏不进预设筛选、5 种类别与 `placeKey`、`usedPresets` / `buildMapLegend` 计数稳定性、过期预设清除、无名预设回退与全维度筛选及路线组合。
- **`mobile/android/app/src/androidTest/java/wang/jscloud/journey/MapFilterAcceptanceTest.kt`**（新增）：
  - 覆盖模拟器浅/深色主题地图图例、筛选面板交互、图例计数展示及预设同步操作。
