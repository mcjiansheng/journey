# 2026-11-11 白板交互与界面修复

依据：[白板交互与界面审查（2026-11-11）](../评审输入/2026-11-11-白板交互与界面/白板交互与界面审查-2026-11-11.md)。分支 `dev`。

## 修改

### 根因 A：未定义的 CSS 变量（问题 1、6，N-6、N-7）
- `board.css` 全面改用正式 token（`--accent`、`--on-accent`、`--optical-panel/edge/shadow`、`--radius-*`、`--fs-*`），删除原型变量；`widgets.css` 的 `--primary`/`--edge` 回退改为 `--accent`/`--optical-edge`（原先在海图蓝主题下也恒为绿色）。
- 新增 `scripts/check-css-vars.mjs`，并入 `npm run tokens:check`：扫描 `app/src` 的 CSS/JSX，`var(--x)` 无回退且无任何定义即失败。白名单仅限运行时注入的局部变量。对改前代码运行可报出 27 处，改后 0 处；`tests/css-vars.test.mjs` 覆盖。
- 路线小组件描边改为 `var(--map-route)`（N-7）。

### 根因 B：画笔草稿层（问题 3、8）
- `#draft` 不再平移 −50000px，改为 1px、`overflow: visible`，位于世界坐标层内。
- 草稿路径用 ref 直接写 `d`（rAF 合并 + `getCoalescedEvents`），不再每次 `pointermove` 复制点数组并重渲染整个白板。
- `board.js` 新增 `strokeLook()` 与 `PEN/HL/NOTE` 色表（全部引用 token），草稿与正式笔迹共用，松手不再跳色跳粗细；荧光笔草稿也带混合模式。
- 画笔/荧光笔/文字工具下对象不拦截指针，可从便签、图片上起笔（旧 P2-14）。

### 根因 C：拖动与缩放（问题 4，N-4、旧 P2-2/4/6/8）
- 本机实况 `localLive` 与同伴实况（由 presence 计算）分开；松手提交与清空在同一批次，不再回跳；同伴心跳不会冲掉本机拖动帧。
- 对象/手柄在自身上 `setPointerCapture`，空白画布与橡皮在 stage 上捕获；`pointerup/cancel/lostpointercapture` 统一结束手势；鼠标移动时检查 `buttons`；3px 拖动阈值，单击不再产生修改。
- `BoardItem`、`BoardWidget` 改为 `React.memo`，回调稳定、以 id 传参；小组件模型按 `widgetDeps()`（加分钟桶）缓存，地图草图按尺寸缓存。
- 手柄与描边按 `--ik = 1/k` 保持屏幕尺寸。
- 小组件形态：四角等比缩放（基准 0.75–1.6 倍，不改形态）；左右拉球 S⇄M、下拉球 M⇄L，`pickWidgetSize()` 带滞回；拖动时显示虚线外框与「小/中/大」标签，形态切换时 160ms 过渡；松手按当前缩放倍数提交。操作条的「小/中/大」也保留缩放倍数。
- presence 的 selected/editing 在部分更新与心跳间保持（原先心跳会清空同伴看到的选中框）。

### 根因 D：布局（问题 2、9，第五节）
- 外壳新增 `immersive-shell`（地图、白板共用侧栏收起与顶栏浮起），`board-shell` 放白板专属规则；偏好文案改为「地图和白板自动收起侧栏」，字段名不变。
- 白板左上为白板切换器（`BoardSwitcher.jsx`）：列表与对象数、新建（立即切换并进入重命名）、重命名、最近删除、删除当前白板（确认、至少保留一块、删除后切到相邻白板）。「最近删除」从右上垃圾桶移入菜单，并列出已删除的白板可整块恢复（白板内对象随白板保留，恢复即复原）。每块白板记住自己的视口（旧 P2-11）。
- 去掉白板自带的顶栏与头像列；顶栏成员头像中正在看这块白板的人加 presence 颜色外圈（N-9）。
- 右下新增缩放控件 `[−] 100% [+] ⤢`（N-10）；工具栏加撤销/重做（⌘Z / ⇧⌘Z），删除后 5 秒「已删除 · 撤销」。
- 点阵背景随平移缩放移动，k<0.4 换稀疏网格（N-11）。
- 空白板显示引导文字。

### 贴纸面板（问题 1）
- 停靠式抽屉：左（默认）/右/下，拖动柄或标题栏拖动，最近边吸附、无自由漂浮，Esc 取消，FLIP 过渡（减少动态效果时直接跳转）；拖动柄方向键切换、右键菜单三选一并播报；窄屏一律底部弹层（60%，点抓手展开 90%）。
- 选择写入账号偏好 `boardPanelDock`（`accountAppearanceKeys`，服务端校验枚举），「我的设置 › 地图与白板」可三选一，与拖动结果一致。
- 「视口中心」「适应全板」均扣除面板所占区域；面板在右/下时缩放控件让位。
- 内容：搜索；概览 2 列缩略图（0.48 倍）；日程每天一行「概览/路线」，路线不足 2 个定位站点置灰并提示，悬停显示实际预览；活动按天折叠，「小/中」直接添加；收藏 2 列（标记色图标 + 两行名称）。
- 添加后不关闭面板，新对象 300ms 放大 + 描边闪烁；支持从面板拖到画布任意位置。

### 其他
