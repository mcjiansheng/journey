# 地图地理编码容错降级与地点搜索保障

依据：用户需求「完成容错降级，将地图编码失败，回退到用户当前城市，且保留搜索入口」。开发分支 `dev`。

## 根因与背景

- 生产环境部分用户将旅程目的地填写为英文缩写或非标准地名（如 `nju`），或旅程目的地为空且尚未添加含坐标的活动/收藏：
  1. 高德地理编码接口 `/_AMapService/v3/geocode/geo?address=nju` 返回 `{"status":"0","info":"ENGINE_RESPONSE_DATA_ERROR","infocode":"30001"}`；
  2. 高德 JSAPI 2.0 `AMap.Geocoder.prototype.getLocation` 插件在收到 `status: "0"` 响应时既不调用 `_geocodingComplete` 也不调用 `_onError`，导致回调永不触发并等待 15 秒超时；
  3. 原 `resolveMapCamera` 在地理编码失败或 `source === 'empty'` 时直接抛出异常，导致 `MapView` 销毁地图实例并渲染「地图暂时无法加载」；
  4. 高德地点搜索 `/_AMapService/v3/place/text` 将 `city=nju` 或 `city=全国` 判定为海外查询并返回 `USER_ABROAD_DAILY_QUERY_OVER_LIMIT`（`10045`）。

## 修改

- `app/src/map-camera.js`：
  - 新增 `currentCityFromAmap(AMap)`，优先读取高德 JSAPI 根据客户端 IP 下发的 `AMap.getConfig().defaultLocation` 城市中心坐标，缺失时回退到默认城市中心 `[116.397128, 39.916527]`。
  - `resolveMapCamera` 在目的地地理编码报错、未返回有效坐标或 `plan.source === 'empty'` 时不再抛错销毁地图，而是回退到用户当前城市（`source: 'current-city'`，`zoom: 12`）；取消信号（`AbortError`）仍保持立即拒绝。
  - `planMapCamera` 在用户尚未手动移动回退视口（`saved.cameraSource === 'current-city'`）且存在非空目的地时，下次进入地图仍重新尝试解析目的地；一旦用户拖动或缩放地图（`cameraSource: 'viewport'`），保留用户视口。
- `app/src/amap.js`：
  - 修复 `geocodeResponse` 调用真实 `AMap.Geocoder` 时对 `status: "0"` 响应透传给 `_geocodingComplete` / `_onError`，避免高德插件吞掉错误回调造成 15 秒卡顿。
  - `searchPlaces` 与 `suggestPlaces` 对非中文/非行政区划代码的 `city`（如 `nju`、`全国`）自动归一化为空字符串以执行全国范围检索；当携带 `city` 参数触发 `ABROAD` / `INVALID` / `ENGINE_RESPONSE_DATA_ERROR` 时自动降级为无城市限制重试一次。
- `app/src/MapView.jsx`：
  - 将 `() => currentCityFromAmap(AMap)` 传入 `resolveMapCamera`，确保地理编码失败或空目的地时地图正常初始化并保留顶部「搜索地点」入口。

## 代码审查与生产防御加固（追修）

1. **`currentCityFromAmap` 零坐标与海外坐标防御**：对高德 `defaultLocation` 增加 `(point[0] !== 0 || point[1] !== 0)` 防御，杜绝 IP 定位失败返回 `[0, 0]` 时将中国用户视口错误重置到几内亚湾大西洋空海域，稳定回退到北京天安门标准中心；并在 `app/tests/map-camera.test.mjs` 补充覆盖用例。
2. **`geocodeResponse` 高德 API 完整性防御**：对 `geocoder._onError` 与 `geocoder.url` 进行防御性校验；增加 `!target` 时立即返回 `NO_PARAMS` 的短路拦截；补齐数组入参 `target.join('|')` 与 `params.batch = true`，严密契合高德 JSAPI 规范。
3. **`searchPlaces` 与 `suggestPlaces` 空查询短路**：在检索前清洗入参 `str(query).trim()`，空白内容直接返回空数组 `[]`，避免发送空请求消耗每日查询限额或引发服务端 400 异常。
4. **验证**：`npm run check`（121 项单测全部通过、构建成功）、`npm run format:check` 通过；E2E 测试 15 项全部通过；部署安全性测试 33 项全部通过。
