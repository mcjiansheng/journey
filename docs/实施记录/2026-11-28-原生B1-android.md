# 2026-11-28 原生 B1（Android）：白板数据与同步层

依据：[11-原生端功能对齐](../设计文档/11-原生端功能对齐.md) 第 1–4、6 节、第 5 节 B1 工作包及 [10-白板](../设计文档/10-白板.md) 第 2–3 节。开发分支：`native/B1-android`（独立工作目录 `../journey-B1-android`）。

## 修改

- **共享用例**（`mobile/tools/generate-fixtures.mjs`、`mobile/fixtures/board-sync.json`）：
  - 新增 `board-sync.json`（33 条用例），由 `app/src/board-pending.js` 直接生成，覆盖 `PENDING_TTL`（15000）、`mergeExpected`、`reconcilePending`（含 `PENDING_TTL` 边界与超期清理、0.01 数值容差、本地新建未入服务端项、删/恢复状态切换）与 `isStaleResponse`。
- **白板规则移植**（`mobile/android/app/src/main/java/wang/jscloud/journey/BoardRules.kt`）：
  - 移植 `BOARD_STYLE_KEYS`、`cleanBoardStylePatch`、`nextBoardStyle`（`app/src/board.js`）。
  - 移植 `normalizeBoardItem`、`cleanBoardItemPatch`、`buildBoardItemCreatePatch`（`app/src/board-sync.js`），保留 `frame / z / content / style / linkedActivityId` 五个独立逻辑组并丢弃 disallowed 样式字段及未知顶层键，对未知 `content.type` / `widget.kind` 安全透传不崩溃。
  - 移植 `mergeExpected`、`reconcilePending`、`isStaleResponse`（`app/src/board-pending.js`）。
  - 移植白板列表与容量口径：`activeBoards`（按 `order` 再按 `id` 排序）、`deletedBoards`、`resolveBoardId`（无自定义白板回退 `default-board`）、`nextBoardOrder`、`canCreateBoard`（≤ 20）及 `boardFullMessage`。
- **白板同步与本机缓存**（`mobile/android/app/src/main/java/wang/jscloud/journey/BoardSync.kt`）：
  - 新增 `BoardCacheStore` 接口、`MemoryBoardCacheStore` 与基于 `java.io.File` + 原子移动的 `FileBoardCacheStore`（按账号与旅程隔离缓存文件，不写进 `account-*.json`）。
  - 新增 `BoardSyncController`：支持 `openBoard`（优先载入本机缓存并在线刷新，离线优雅保留缓存）、`refreshActiveBoard`（`?since=` 增量合并；`epoch` 变化时丢弃 `cursor` 全量重读；`isStaleResponse` 丢弃旧游标响应）、`addBoardItem` / `patchBoardItem` / `deleteBoardItem` / `restoreBoardItem`（乐观写入 + `reconcilePending` 防旧回显闪烁 + 入队操作）与 `onOperationRejected`。
- **共用文件接线**：
  - `Api.kt`：`JourneyApi` 实现 `BoardItemsApi.fetchBoardItems(tripId, boardId, since)`（`GET /api/trips/:id/boards/:boardId/items`）。
  - `Domain.kt`：`projectSnapshot` 跳过 `objectType == "boardItem"` 的待同步操作（与网页 `sync.js` 保持一致）。
  - `JourneyStore.kt`：接入 `boardSync`、白板 CRUD（`boards`、`deletedBoards`、`openBoard`、`refreshBoard`、`createBoard`、`patchBoard`、`deleteBoard`、`restoreBoard`）与供 N2 SSE `change` 对接的 `onRemoteTripChange`；修复 `sync()` 对 `boardItem` 操作省略 `snapshot` 的回执校验、支持过期 `generation` 删除/恢复返回 HTTP 200 且 `receipt.changed=false` 视为成功出队、并针对 `BOARD_FULL`（409）透出明确中文提示与拒绝回调；前后台切换、12 秒定时轮询、登出/切账号/切旅程/退旅时联动刷新或清理白板状态。
- **测试**：
  - `SharedFixturesTest.kt`：接入 `board-sync.json`，并将 `board-geometry.json` 的 `cleanBoardStylePatch` / `nextBoardStyle` 与 `board-sync.json` 的 `mergeExpected` / `reconcilePending` / `isStaleResponse` 全部逐条比对。
  - `BoardSyncTest.kt`：单测覆盖 `normalizeBoardItem`、`cleanBoardItemPatch`、白板列表排序与容量限制、`projectSnapshot` 跳过 `boardItem`、`MockWebServer` 下的全量/增量拉取、`epoch` 变化全量重读、旧游标丢弃、待确认保护、删除/恢复、`BOARD_FULL` 拒绝回调与持久化缓存重启恢复。
  - `BoardIntegrationTest.kt`：针对真实联调服务验证 `default-board` 惰性读取与规范化、Web 端写入便签的读取校验、Android 端离线排队与顺序重放（含 5 组 patch 校验、服务端省略 `snapshot` 校验）、过期 `generation` 删除/恢复 `receipt.changed=false`、以及 20 块白板上限触发 HTTP 409 `BOARD_FULL`。
