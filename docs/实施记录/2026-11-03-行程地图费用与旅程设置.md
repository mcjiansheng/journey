## 修改

- Web 桌面行程移除排序开关，悬停或键盘聚焦显示拖动手柄；手机从当天菜单进入单行排序模式。有具体时间的安排显示锁定时间说明。
- 三端费用空日期跟随关联活动所在日期；手填日期保持固定。列表显示活动名称和时间，点击进入行程并定位；活动被删除时显示对应状态。
- 旅程设置按基本信息、日程、成员与权限、整理、退出操作分组；单人文案改为“仅你一人”，时区可搜索。
- 改期先选择范围，再按影响选择整体移动、保留原日期或逐项选择；仅延长结束日期直接保存。整天交换移入当天菜单。日历两次点击选择范围，旧范围外日期显示虚线。
- 新增地图专用浅底图颜色 token；主题变化重画路线。收藏可选八种形状、八种颜色，支持共享预设、图例和筛选。聚合保留单独的选中地点和行程序号，名称最多八字。
- Web 名称交由高德 LabelMarker / LabelsLayer 绘制，开启文字避让。自绘图标独立保留；自有名称放置仍先按优先级避免图标碰撞。
- Android 使用 GeoJsonSource / SymbolLayer 绘制收藏和名称；iOS 用 MapReader 将地点投影到屏幕并在相机移动结束后聚合。
- 收藏 mark 独立计时钟；markPreset 组合在旅程内唯一，修改组合在服务端同一事务更新匹配收藏，删除预设保留收藏标记。
- 发布打包补入服务端新增依赖 marks.js。

## 实现说明

收藏没有独立的不可变创建时间字段，聚合输入用对象 ID 保持稳定顺序。名称避让按平台处理：Web 使用高德文字图层，Android 使用 SymbolLayer，iOS 使用系统标注标题。

Android 聚合插入/移除未实现固定 150ms 过渡；MapLibre 当前公开过渡接口仅控制绘制属性，未增加定时器模拟。iOS 已接入 150ms 动画和系统减少动态效果。

Android 当前 OSM 底图是栅格瓦片，SymbolLayer 能避让自己的名称，无法读取瓦片里的地名做碰撞。iOS 标注标题交给 MapKit 自动显示；原生两端采用同一分组规则，名称放置使用各自地图引擎。

高德文字图层配置依据：[海量标注官方文档](https://developer.amap.com/api/javascript-api-v2/guide/amap-massmarker/label-marker)。

本机 npm 启动报 gracefulify is not a function，Web 检查直接使用已安装的 Node、Vite、Prettier 和项目浏览器运行脚本，未改全局工具配置。
