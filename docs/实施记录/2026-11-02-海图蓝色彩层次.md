# 2026-11-02 海图蓝的色彩层次与渐变

## 问题

森林绿的浅色和深色都有三层关系：带光晕渐变的页面 → 半透明侧栏 → 卡片。海图蓝的三个环境光 token（`ambientMint / ambientSky / ambientLow`）全部是透明色，`page-background` 只有纯色 `var(--bg)`。深色下页面、侧栏、卡片又都落在同一段中蓝里（`#102632 / #152e3c / #193543`），所以既没有渐变，也分不出层次。

## 思路

沿用森林绿的结构（同样的三处光晕位置和侧栏材质），只把颜色换成“海图”的语汇：

| 光晕位置 | 森林绿 | 海图蓝 · 浅色 | 海图蓝 · 深色 |
| --- | --- | --- | --- |
| 左上 | 薄荷 | 浅海青 `#cde7f0b3` | 深海青 `#2a9cc27a` |
| 右上 | 天青 | 晨雾蓝（略带紫）`#dde2f6a8` | 夜空靛蓝 `#4a5fc452` |
| 底部 | 暖米 | 海图纸色 `#f8f1e299` | 海水微光 `#157a8a40` |

层次：

- **深色**：页面压到接近黑的深海蓝 `#0a151c`，光晕才有空间显出来；侧栏 `#0e1b23d9` 比页面稍亮、半透明；卡片 `#13242e`、浮层 `#162a35` 再亮一级。线条、选中、头像、图标底色同步调暗，避免在更暗的页面上发亮。继续旅程卡片和费用合计改为 `#1d4a62 → #13303f` 的斜向渐变（对应森林绿的 `hero-surface`）。
- **浅色**：页面底色不变，加三处光晕；侧栏改为近白半透明 `#f9fcfdad`，和页面拉开明度差（原来 `#e4edf3c9` 比页面还暗，和页面混在一起）。

## 顺带修复

- 全局焦点框原来写死为绿色 `#4b967d`，海图蓝下也是绿框。新增 `focus-ring` token：森林绿保持 `#4b967d`，海图蓝浅色 `#2f86a6`、深色 `#6fb9d6`。
- 侧栏底部头像按钮的分隔线原本是按钮自己的上边框，焦点框会把分隔线一起圈进去，而且是直角。分隔线移到 `.sidebar-foot::before`，按钮加圆角，焦点框只圈住头像和名字。

## 改动

- `design/tokens.json`：海图蓝浅色 7 项、深色 25 项；两套主题新增 `focus-ring`。
- 重新生成：`app/src/tokens.css`、`app/src/palette-meta.js`、`app/public/appearance-init.js`、`DesignTokens.swift`、`DesignTokens.kt`。iOS、Android 的背景本来就读三个环境光 token，所以原生端同样有了渐变。
- `app/src/styles.css`、`app/src/map-markers.css`：焦点框改用 token；侧栏底部分隔线和按钮。

## 验证

- `npm run tokens:check`、`npm run contrast:check`（72 项）通过。深色下正文与卡片对比度 13.4 : 1，次要文字 8.1 : 1，选中底板与卡片 2.1 : 1。
- 网页在本地构建运行，截图核对四种组合（绿 / 蓝 × 浅 / 深）的行程页、首页、费用页和键盘焦点。
