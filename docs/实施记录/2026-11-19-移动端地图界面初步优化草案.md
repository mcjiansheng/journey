# 2026-11-19 移动端地图界面初步优化草案

依据：[移动端网页问题追踪清单](../评审输入/移动端网页问题追踪清单.md)（`MOB-006 ~ MOB-008`、`MOB-018 ~ MOB-021`）。  
分支说明：所有改动均在基于 `dev`（`05d8093`）创建的独立分支 `draft/mobile-map-ui` 上完成，**仅作为初步 UI 设计方案与交互验证草案，不作为最终发布成果，不合并至 `dev` 或 `main`**。

## 一、核心界面改造

| 对应条目 | 问题摘要 | 本次初步优化方案 |
| --- | --- | --- |
| `MOB-006` | 顶部展开大面板与右下角图例、底图三层碰撞，`setFitView` 压缩视口至 `500 公里` 且左侧标点裁切 | 将 `#map-place-panel` 拆分为顶部悬浮区（`.map-top-dock`：独立搜索框 + 紧凑胶囊条）与底部抽屉（`.map-sheet-surface`）；为 `.map-canvas` 建立 `z-index: 1; isolation: isolate` 层叠上下文避免地图标点穿透浮层；通过 `ResizeObserver` 监听 `.map-top-dock` / `.map-sheet-surface` / `.map-peek-bar` 实时更新 `--map-top-clearance` 与 `--map-bottom-clearance`，重算 `setFitView` 与 `shiftCamera` 的无遮挡中带居中。 |
| `MOB-007` | 手机端隐藏 `+` / `−` 地图缩放按钮 | 在右下角恢复竖排毛玻璃缩放/定位胶囊（`+`、`−`、`⌖`），随 `--map-bottom-clearance` 动态停靠在 Peek Bar 或抽屉上方；在搜索、全屏筛选/编辑或抽屉全展开（`.map-tools-hidden`）时自动隐退避免重叠。 |
| `MOB-008` | 左下角比例尺、高德版权、`temp-amap` 提示牌与图例互压 | 图例迁至顶部按需弹层后释放左下角空间；无 Key 预览提示收敛为短文案 `预览地图 · 未配高德 Key`，与比例尺/高德控件统一基于 `--map-bottom-clearance` 分层避让并在抽屉全展开时随 `.map-tools-hidden` 一并隐退；修复软键盘弹出态（`.map-keyboard-open`）下底部抽屉从 `--map-top-clearance` 下方锚定、底部不落入虚拟键盘区域。 |
| `MOB-018` | `+ 加入行程` 按钮挤压折行、顶部控件留白与日期箭头比例失衡 | 全端（含桌面 `350px` 侧栏与手机端）为 `.map-actions > button` 设置 `white-space: nowrap` 与 `1.25 : 1 : 1` 弹性分配，消除 `+ 加入行程` 折行；移动端操作条改为横向不换行单行滚动（`flex-wrap: nowrap; overflow-x: auto`）；移动端 `MapRoutePicker` 改为紧凑胶囊（日期文本紧跟 `∨` 箭头），日期筛选与图例胶囊同排，并高亮 `mode-filter` 激活态。 |
| `MOB-019` | 收藏标记 8+8 网格默认全量展开挤出「导航到这里」、图例常驻遮挡画布 | 移动端（`≤760px`）为 `FavoriteMarkEditor` 增加可折叠摘要栏（`.mark-mobile-toggle`：展示当前图形/色点与预设名，点击切换全量选板并联动展开底部抽屉），桌面端保持直接内联展示；移动端 `.map-legend` 默认收纳至顶部「图例 N」开关胶囊，点击在右上角展开浮层并支持点击外部或 `Esc` 收起。 |
| `MOB-020` | 临时交互地图（`temp-amap.js`）低缩放下城市水印相互压盖 | 在 `temp-amap.js` 的 `_renderBackdrop()` 中增加城市水印屏幕坐标安全距离过滤（`|Δx| < 88px && |Δy| < 26px` 跳过且避开画布边缘）。 |
| `MOB-021` | 地图次级态底栏（`.bottom-nav`）叠压拥挤、隐藏后左上角返回语义断点及缺乏三段式流畅抽屉 | **1. 上下文隐藏底栏 + 返回语义切换（`App.jsx` + `MapView.jsx`）**：仅浏览总览态（`browse` 且非搜索/未全展/未弹键盘）显示 `.bottom-nav`，此时左上角箭头为「返回我的旅程」；进入 `detail`/`list`/`search`/`filter`/`manual`/`pick` 等子视图时，`.app-shell.map-nav-hidden` 隐藏 `.bottom-nav` 并下移提示条，左上角箭头切换为「返回地图总览」，先回到带 `.bottom-nav` 的地图 `browse` 态再决定切页或返回旅程列表。<br>**2. 三段式连续拖拽抽屉 + Peek Bar**：`browse` 态于 `.bottom-nav` 上方提供独立概览条 `.map-peek-bar`（当天行程点 + 收藏汇总 + `列表 ∧`），点按或上滑进入贴底圆角抽屉（`border-radius: 22px 22px 0 0; bottom: 0`）；窗口级 `pointermove`/`pointerup` + 滚动区触顶下滑接管，实时更新 `--sheet-drag-height` 与 `--sheet-drag-y`，支持 `Peek ↔ 半屏 ↔ 展开` 连续跟手拖拽。<br>**3. Google Maps / 高德地图克制精简**：搜索态左侧增加 `<ArrowLeft />` 取消、有输入时右侧增加 `×` 清空；详情固定非滚动头部内置圆形快捷导航按钮（`.map-quick-nav`）；列表模式按天区分「行程点序标区 + 共享收藏」并配显式 `×` 关闭。 |

### E2E 断言调整与新增回归说明（依 `AGENTS.md` 记录原因）

1. `map-layers.spec.mjs`（210–215、236、253 行）：因需求改为移动端默认折叠 `FavoriteMarkEditor`（`MOB-019`），在 `width <= 760` 用例中新增点击 `.mark-mobile-toggle` 展开摘要后再校验 8+8 图形/颜色选板与预设交互；桌面端（`1440px`）断言保持不变。
2. `map-controls.spec.mjs`：
   - 196–228 行：因地图子视图隐藏 `.bottom-nav` 并将左上角返回设为「返回地图总览」（`MOB-021`），更新为验证在编辑/详情态下 `.bottom-nav` 隐藏且显示「返回地图总览」，点击后先返回 `browse` 态并恢复 `.bottom-nav`、`返回我的旅程` 与 `.map-peek-bar`。
   - 237–242 行：将窄屏筛选滚动检测精确收紧为 `['auto', 'scroll'].includes(overflowY)`，实际验证 `.map-sheet-surface` 在 `320×500` 下的滚动能力。
   - 293–328 行（新增回归）：`mobile peek bar opens flush sheet, swipe down dismisses, and top-left back returns to browse nav`，验证 Peek Bar 不与底栏重叠、点击后贴底（`bottom >= 843`）且隐藏底栏、手柄展开/收起、下滑手势关回总览态及搜索左侧返回按钮。
3. `map-selection.spec.mjs`（72–106、128 行）、`map-camera-motion.spec.mjs`（71–77 行）与 `place-information.spec.mjs`（171 行）：因移动端改为 Top Dock + 贴底 Bottom Sheet 且详情态隐藏 `.bottom-nav`（`MOB-006`、`MOB-021`），更新可视画布带检测以 `.topDock.bottom .. sheet.top` 为界，并在测试移动端通过底栏切换至「行程」前先点击「返回地图总览」退出地图子视图（上述真 SDK 用例因当前环境未配置 `AMAP_KEY` 暂未实跑高德网络流程）。
