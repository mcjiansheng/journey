依据：[11-原生端功能对齐](../设计文档/11-原生端功能对齐.md) 第 5 节 N2 与「本轮并行要点」N2。分支：`native/N2-ios`（工作目录 `../journey-N2-ios`，2026-11-27 开始），合回 `dev`。规则按网页 `main`（`3d5a2e4`）的 `app/src/sync.js` `subscribeTrip` / `accessFailure` 与 `app/server/index.mjs` 的 `/api/trips/:id/events` 移植。

## 修改

- **`mobile/ios/Journey/EventStream.swift`（新增）**
  - `EventStreamParser`：按 WHATWG「Server-sent events」逐字节解析 `text/event-stream`。CR / LF / CRLF 换行（CRLF 跨块也只算一次）、多行 `data` 以 LF 拼接、`:` 注释行（服务端的 `: heartbeat`）、无 `data` 的事件不派发且类型不延续、`id` / `retry` 字段、仅去掉开头一个 BOM、连接中断时丢弃未结束的事件。按字节处理，多字节 UTF-8 字符被拆在两块里也得到同样结果。
  - `EventStream`：用 `URLSession.bytes(for:)` 读取，读取放在主线程之外，事件回到主线程派发。断线按指数退避重连（1 s 起翻倍，上限 30 s，±20% 抖动；`retry:` 只能拉长首档）；收到事件即重置退避。429（每用户每旅程 4 条上限）等待最长一档后重试；401 / 403 / 404 / 410 与 `revoked` 停止，不再重连；200 但不是事件流按失败退避。停止时取消数据任务，服务端随即释放该连接名额。
  - `LiveUpdates` 与 `JourneyStore` 扩展（接线）：
    - 只为当前打开的旅程保持一条连接，且需已启动、已登录、会话未过期、处于前台；切换旅程、回到我的旅程、登出、会话过期都会关闭或替换连接。
    - `change`：解析 `{cursor,epoch}`，与本机快照比较（同网页：epoch 更旧、或 epoch 相同且 cursor 不大于本机的跳过），需要时重读。
    - `revoked` 或连接被拒：与网页一样重读快照弄清原因——403 / 404 / 410 按网页 `accessFailure` 退出旅程（410 / `TRIP_PURGED` 同时清除本机副本与待上传修改）、从列表移除并显示服务端消息（如「你已不在此旅程团队」）；401 进入重新登录。
    - `rereadTrip`：打开旅程、前台轮询、`change` 通知共用的重读入口，进行中的读取被复用，不重复请求；一条通知若遇到在其之前发出的读取，最多再读一次。
    - 前台 8 秒轮询保留为兜底：只有在流在线（25 秒内有数据，服务端每 15 秒心跳）且快照已追上最新通知时才跳过快照读取；队列上传、租约续期照旧。
    - `setForeground`：进入后台断开，回到前台重连；服务端连接建立时发出的当前游标触发补读。
    - `onTripEvent`：订阅当前旅程的所有事件（`change`、`presence`、`revoked` …），供白板 B1（增量拉取）与 B8（在线提示）使用，返回取消订阅的闭包。
    - `leaveTrip`：主动退出旅程。服务端在回复前就向本机的流发 `revoked`，退出期间不把它当成被移出而弹提示。
- **共用文件只做接线**：`JourneyStore.swift`（`selectedTrip`、`sessionExpired` 变化时更新连接；`open` / `refresh` 改走 `rereadTrip`；轮询按 `pollShouldRefresh`；`persist` 改为模块内可见），`JourneyApp.swift`（`scenePhase` 变化时调用 `setForeground`，后台以外都算前台），`ManageViews.swift`（退出旅程改调 `leaveTrip`）。
- **`app/CONTRACT.md`**：events 接口原写「只推 event:change」，与 `main` 代码不符。按代码补全：鉴权失败的状态码、`presence`（连接时补发 15 秒内条目）、`revoked` 的触发条件（被移出、旅程清除、该会话登出、会话失效）、15 秒复查与 `: heartbeat`。
- **测试**：新增 `JourneyTests/EventStreamTests.swift`，并重新生成 Xcode 工程（只新增条目）。

### 共享用例

### 与网页双向互通
