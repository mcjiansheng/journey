# 2026-10-13 已确认实施决策

本轮以正式设计 v0.9（含 C23）为依据，用户在实施中补充以下决定。

- 项目是大学生课程项目，目标完成度达到上线水准。本次账号采用手机号或邮箱标识加密码注册与登录，不要求实际短信或邮件验证。服务端保存加盐 scrypt 密码摘要；不提供固定验证码或测试身份入口。真实邮件、短信接口保留为后续部署配置。
- 部署在现有 L4D2 主机，独立域名 `journey.jscloud.wang`。复用现有 443 监听，独立证书、反向代理站点、系统用户、进程和数据库。不得影响游戏及控制器的既有配置。
- 前端需要美观精致，保留简洁绿色品牌、Liquid Glass 与流畅动效。设计验证以真实业务内容和不同视口的浏览器截图为准。

普通技术选择及尚未细定交互采用以下最小方案。

- Node.js 22.13 以上，Express、React、SQLite WAL；SQLite 事务提交后才向成员推送 SSE 更新。课程项目单实例运行，CPU 和内存由 systemd 限制。
- 手机导航为行程、地图、费用、设置。地图填满应用视口，控件浮于地图之上；从旅程回首页保留账号、成员关系、当前页、选中日期、编辑草稿、滚动和地图相机上下文。
- 归档只整理本人的旅程列表。永久清除只发生在最后一位成员明确确认退出时；临时删除适用于旅程、计划日、活动、收藏、费用和路程，统一提供恢复入口。
- 费用按币种分别合计，不自动换汇；预计金额可空，实际支付必须有合法金额，0 元允许。支付状态与金额、币种整体合并。
- 日历日期移动时用户选择随日期一起移动的活动；未选项保持原日期、时间。计划范围外内容保留并可重新安排。
- 离线队列与快照写入同一 IndexedDB 记录，按账号隔离。页面存续期用服务器时钟租约和单调计时确定修改发生时刻。离线刷新后的新编辑无法校准发生时刻时，保留草稿和队列，联网后由用户明确重新应用；已经排队的可信修改自动补传。
- 独立安全账本保存身份、权限撤销、邀请失效和永久清除边界。业务备份恢复时保持最新安全账本；恢复后的新 epoch 使客户端接受回退过的业务游标，权限不随旧备份回退。
- 通知仅提供用户主动开启的浏览器协作提醒，连接页面收到同伴更新后触发。尚无后台推送或行程闹钟。
- 高德公开 JS Key 供 SDK 使用，安全密钥只存服务器受限文件，通过固定高德接口代理注入。插件采用官方异步加载完成回调后创建，见[官方服务插件说明](https://lbs.amap.com/api/javascript-api-v2/guide/services/autocomplete)。

## 设备反馈与视觉补充

用户继续确认以 `sites/journey-main-direction/dist/index.html` 为界面参考，强调 Apple 风格玻璃材质、柔和光学、渐变色彩。正式界面采用浮动侧栏、半透明的地图控制面板、浅色日期选中态和清楚的内容层次。仅沿用视觉方向。

手机优先 iOS，Android 以原生系统浏览器环境验证。轻提示音默认关闭，由用户在共用个人设置主动开启；触感反馈按浏览器真实能力调用。iOS 使用真正的原生设置开关：Safari 18 已为 `input type=checkbox switch` 提供系统触感（[Apple 发布说明](https://developer.apple.com/documentation/safari-release-notes/safari-18-release-notes)）。通用 `navigator.vibrate` 当前未在 WebKit 实现，支持情况见 [W3C 实现报告](https://w3c.github.io/vibration/reports/implementation.html)。电脑使用精细指针悬停高光与按压反馈；减少动态效果、减少透明和深色模式独立生效。

高德当前 JS API 插件加载器使用 `eval` 执行 SDK 返回的插件代码，因此 CSP 的脚本策略允许 `unsafe-eval`，脚本来源仍限制为本站、高德及其底图域名；安全代理继续限制目的域、接口、参数与回调名称。真实 SDK 的相同重复参数合并为一个，冲突重复参数拒绝。
