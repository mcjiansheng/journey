# 多人协作旅行规划工具

**设计基线：v0.9 · 2026-10-12**

项目处于设计阶段，正式应用尚未开始实现。本仓库收录设计文档、研究材料和评审记录；既有原型与界面可视化保留在本地，通过 `.gitignore` 排除。

面向熟人结伴旅行的响应式Web工具。以行程、地图和费用组织共同规划：先记录想法，逐步安排，出行时继续使用同一份行程。

开发团队3人，2026年12月底交付完整应用，以可上线质量和测试证据为目标，不要求实际公网发布。正式覆盖电脑及iOS、安卓手机浏览器；安装能力留作后续扩展。

## 当前设计

- 手机号或邮箱登录；继续完整恢复旅程上下文。创建时选择管理员团队或平等团队，创建者离开后按团队类型和加入顺序继任。分享通过编码、手机扫码或邀请链接加入同一团队，邀请期生成时选择。
- 行程按天呈现，活动可以直接选址；时间包括通勤和提前到场缓冲。未确定内容可以留白。
- 地图采用高德JS API 2.0及配套服务，收藏全团队共享，默认展示全部，可突出某天路线并按类别、安排状态筛选；费用独立记账，以已支付为主，支付后实际金额替换原预计。
- 完成修改自动保存并在线共享；离线持久存本机，联网自动补传。同内容按修改发生时间取最新，临时删除不被普通编辑解除，恢复后保留期间新修改；最后一人退出永久清除旅程。
- 平等团队集体删除须有人明确希望删除，且不参加或希望删除的去重人数过半；仅不参加过半时保留。创建者/管理员可直接恢复，成员可过半支持恢复。通用沟通和强制定稿不进入主线。
- 视觉采用类LiquidGlass及简洁流畅动画，从无图、少量真实内容的布局开始设计。

正文已统一替换旧方案中的冲突规则。两类团队、离线、删除恢复及日期联动已确定；地图、邀请管理、表态重算与归档继任规则也已确定，混排、模式切换、继任后备选择和邀请失效规则见[05设计决策](docs/设计文档/05-小组设计决策工作坊.md)。

## 既有原型

原型保留为本轮讨论的参考，功能与样例数据沿其制作版本；v0.9尚待实现。

- 本地 `prototype-v4/README.md`：在该目录执行 `npm start`，打开 http://localhost:4176/ 。**按 v0.9 基线重新实现**：行程/地图/费用三入口、活动直接编辑与选址、全视口地图与玻璃悬浮控件、已支付账本、自动保存与同步状态、离线补传、两类团队与删除恢复表态；右下角原型控制条可切换手机/电脑视图、深浅主题、身份与协作模拟。附 29 项模型与冒烟测试（`npm test`）。
- 本地 `prototype-v2/README.md`：在该目录执行 `npm start`，打开 http://localhost:4175/。2026-10-08记录19项模型测试和部分浏览器流程通过。
- 本地 `prototype/README.md`：在该目录执行 `npm start`，打开 http://127.0.0.1:4173/。2026-10-07记录29项自动测试通过。
- prototype-v3 为 v0.5 时期的单文件地图主导布局探索（`prototype-v3/index.html`），随旧规格保留参考。

v1/v2/v3 均为旧规格原型；v0.9 的当前范围以 prototype-v4 与设计文档为准。上述原型均为单人、本机保存的前端原型。真实账号、云端协作、地图及正式手机验收在后续实现与验证。
