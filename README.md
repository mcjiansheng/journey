# 多人协作旅行规划工具

**正式应用 v1.0 · 设计基线 v0.9 / C24–C26 · 2026-10-13**

访问：[journey.jscloud.wang](https://journey.jscloud.wang/)。

正式应用位于 `app/`，使用 React、Express 与 SQLite，包含真实账号、协作行程、高德地图、费用、成员权限、离线保存与冲突合并。既有原型与 Sites 界面参考保留在本地，通过 `.gitignore` 排除。

面向熟人结伴旅行的响应式Web工具。以行程、地图和费用组织共同规划：先记录想法，逐步安排，出行时继续使用同一份行程。

按本轮确认决定，课程项目使用手机号或邮箱加密码注册登录；短信和邮件验证码留作正式运营接入。部署入口采用 `journey.jscloud.wang`，与现有 L4D2 隔离运行。界面优先适配 iOS 浏览器、原生 Android 与电脑，使用 Liquid Glass 光学层次和响应式导航。

## 启动与维护

```sh
cd app
npm ci --cache ../.local/npm-cache
npm test
npm run build
npm start
```

默认访问 `http://127.0.0.1:4177/`。高德需通过 `AMAP_CONFIG_FILE` 指向私密 JSON（`key` 和 `securityJsCode`），或配置对应环境变量。服务默认数据库位于 `app/data/`，运行数据和凭据不入库。开发热更新运行 `npm run dev`，API 由 Vite 代理到 4177。

## 产品范围

- 手机号或邮箱登录；继续完整恢复旅程上下文。创建时填写目的地和起止日期，时区默认目的地当地，并选择管理员团队或平等团队，创建者离开后按团队类型和加入顺序继任。分享通过编码、手机扫码或邀请链接加入同一团队，邀请期生成时选择。
- 行程按天呈现，活动可以直接选址；时间包括通勤和提前到场缓冲。未确定内容可以留白。
- 地图采用高德JS API 2.0及配套服务，收藏全团队共享，默认展示全部，可突出某天路线并按类别、安排状态筛选；费用独立记账，以已支付为主，支付后实际金额替换原预计。
- 完成修改自动保存并在线共享；离线持久存本机，联网自动补传。同内容按修改发生时间取最新，临时删除不被普通编辑解除，恢复后保留期间新修改；最后一人退出永久清除旅程。
- 平等团队集体删除须有人明确希望删除，且不参加或希望删除的去重人数过半；仅不参加过半时保留。创建者/管理员可直接恢复，成员可过半支持恢复。通用沟通和强制定稿不进入主线。
- 视觉采用类LiquidGlass及简洁流畅动画，从无图、少量真实内容的布局开始设计。

正文已统一替换旧方案中的冲突规则。两类团队、离线、删除恢复及日期联动已确定；地图、邀请管理、表态重算与归档继任规则也已确定，混排、模式切换、继任后备选择和邀请失效规则见[05设计决策](docs/设计文档/05-小组设计决策工作坊.md)。

- 本地 `prototype/README.md`：在该目录执行 `npm start`，打开 http://127.0.0.1:4173/。2026-10-07记录29项自动测试通过。
- prototype-v3 为 v0.5 时期的单文件地图主导布局探索（`prototype-v3/index.html`），随旧规格保留参考。
